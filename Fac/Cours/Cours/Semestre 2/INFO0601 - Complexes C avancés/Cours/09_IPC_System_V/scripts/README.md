# Scripts of course #9

## Compilation

To compile, type the following command:

```bash
make
```

## Programs/files

Here is the list of the generated programs or files used:
- `queue/create`: create a message queue
- `queue/create_private`: create a private message queue
- `queue/use`: using a message queue
- `queue/delete`: delete a message queue
- `queue/example/`: full example of using a message queue
- `segment/create`: create a shared memory segment
- `segment/example1` and `segment/example2`: using a shared memory segment
- `segment/delete`: delete a shared memory segment
- `segment/mapping1` and `segments/mapping2`: mapping example of a shared memory segment
- `semaphore/create`: create a semaphore set
- `semaphore/infos`: get informations about a semaphore set
- `semaphore/get`: get the value of one or all semaphore in a set
- `semaphore/set`: changes the value of one or all semaphores in a set
- `semaphore/delete`: delete a semaphore set
- `semaphore/example1` and `semaphores/example2`: using a semaphore set
