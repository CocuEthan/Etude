# Scripts of course #3

## Compilation

To compile, type the following command:

```bash
make
```

## Programs/files

Here is the list of the generated programs or files used:
- `example`: used to test the `strace` command
- `write`: using `open`, `write` et `close`
- `read`: using `open`, `read` et `close`
- `reposition`: reposition offset file with `lseek`
- `truncate`: truncate a file with `ftruncate`
- `stream_write`: write in a file with a stream
- `stream_read`: read in a file with a stream
- `directory`: read recursively a directory (test directory `dir`)
