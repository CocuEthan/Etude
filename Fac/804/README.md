## Modèles non versionnés

Les modèles Keras entraînés (`*.keras`, ex. `meilleur_modele.keras`,
`meilleur_modele_VII.keras`) ne sont pas dans le dépôt (voir `.gitignore`) :
ils sont volumineux et **régénérables** en relançant les scripts d'entraînement
des TP correspondants. Les courbes d'apprentissage (`courbe_*.png`) sont conservées
comme trace des résultats.
