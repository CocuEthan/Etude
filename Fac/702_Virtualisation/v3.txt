On commence par récupérer la v1
# 1. Créer le dossier v3 et y aller
mkdir -p ~/projet/v3
cd ~/projet/v3

# 2. Copier les indispensables depuis la v1 (Dockerfile, binaires, libs)
cp ../v1/geonet .
cp ../v1/buscom .
cp ../v1/libasnd.so .
cp ../v1/libbuscomd.so .
cp ../v1/Dockerfile .

# 3. Copier le dossier de config de base
cp -r ../v1/config .
mkdir logs

récupérer ip des worker: ip a

Maintenant on gère le déploiement. On retourne sur le manager


on crée le fichier yml: nano stack.yml

on rentre ceci a l'intérieur:

version: "3.8"

services:
  buscom:
    image: projet_v3
    deploy:
      mode: global
    user: utilisateur
    command: /usr/bin/buscom
    volumes:
      - /home/ubuntu/projet/v3/config:/etc/its/config
    networks:
      - hostnet

  geonet:
    image: projet_v3
    deploy:
      mode: global
    cap_add:
      - NET_ADMIN
      - NET_RAW
    volumes:
      - /home/ubuntu/projet/v3/config:/etc/its/config
      - /home/ubuntu/projet/v3/logs:/var/log/its
    command: sh -c "rm -f /tmp/geonet.lock && /usr/sbin/geonet -fnmlt"
    networks:
      - hostnet
    depends_on:
      - buscom

networks:
  hostnet:
    external: true
    name: host
On lance le déploiement: 
pour les worker: sudo docker swarm join --token <TOKEN> <IP_MANAGER>:2377
pour le manager: sudo docker stack deploy -c stack.yml projet_its

Pour vérifier le bon fonctionnement:
Sur workers 2: sudo docker ps
puis sudo docker logs -f <ID_BUSCOM> | grep --line-buffered "cam"

Sur le manager: sudo docker stack ps projet_its
